# NotebookLM upload guide

Upload the numbered Markdown files as sources. Each file contains readable study content and source references inline; none requires Obsidian or another local Markdown file to make sense. Files are divided by dated month, with a separate unknown-year sequence and undated references. Uploaded dates retain the uncertainty of the originals.

Start with 00-Overview.md, 01-Dictionary.md and 02-Grammar.md. Then add the chronological groups relevant to your session. To retain exact exercises and image evidence, add the relevant monthly files and undated-reference groups. Do not treat quoted learner answers as corrected models.

The Images folder contains original-byte copies of text-bearing/diagram images selected for separate upload. Image-manifest.md identifies them and every source occurrence. If the interface does not accept an individual image, keep it beside the export as review evidence; the Markdown includes its description, available OCR and consolidated teaching content. Layout-dependent maps and uncertain handwriting should be reviewed visually. No claim about current NotebookLM upload limits is made.

The original DOCX/XLSX/audio/video files remain in their existing locations; they are not modified or moved. For listening sources, upload the original recording separately if you want its speech covered. Its path and duration appear in the export. Speech was not transcribed here.

Review 03-Review-and-verification.md for unresolved issues and the original hash check. Vocabulary is broad but not certified exhaustive while OCR fine print and speech remain unresolved.
